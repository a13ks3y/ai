# AI Visual Studio Code Extension

This project is an initiative to develop an AI that can proactively write to you first. The extension integrates with Visual Studio Code to combine Ollama emails and bash command execution.

## Features

- **Proactive AI Communication**: The AI can initiate conversations and write emails to you.
- **Bash Command Execution**: Execute bash commands directly from the extension.
- **Integration with Ollama**: Seamlessly integrates with Ollama for email management.

## Installation

To install the extension, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/a13ks3y/ai.git
    ```
2. Open the project in Visual Studio Code:
    ```bash
    code ai/aivs
    ```
3. Install the required dependencies:
    ```bash
    npm install
    ```

## Usage

1. Open the command palette in Visual Studio Code (`Ctrl+Shift+P` or `Cmd+Shift+P` on macOS).
2. Search for `AI: Start` to initiate the AI.
3. Follow the prompts to configure email settings and bash command preferences.
